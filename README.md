# Casualties: Rimknown
Casualties: Rimknown Mod integrates elements of Casualties: Unknown into RimWorld.
## Current [Development Phase](#Development-Phases):
* **Active Phase: Phase 1**
	* Phase #1 consist of adding the base layer for Factions from the C:R Alt-canon, including the backstories, cultures, etc.
	* Also includes re-implementing all the features from [**Casualties: Rimknown - Sound Cannon**](https://steamcommunity.com/sharedfiles/filedetails/?id=3768377243) and some additional drugs.
## Lore
**Casualties: Rimknown is an alt-canon where the events of Casualties: Unknown take place in the universe of RimWorld.**

## Development Phases
Disclaimer: Development Phase Items subject to change at any time, nothing here is promised!
* **Phase #1** - consist of adding the base layer for Factions from the C:R Alt-canon, including the backstories, cultures, etc. Also includes re-implementing all the features from [**Casualties: Rimknown - Sound Cannon**](https://steamcommunity.com/sharedfiles/filedetails/?id=3768377243) and some additional medicines.
* **Phase #2** - consist of adding the armor and weapons from Casualties: Unknown and having all three factions spawn with the correct equipment. Also, expanding on The Company™, possibly adding a tech print for the Uni-health Brain Chip.
* **Phase #3** - creating **Casualties: Rimknown - Grey Planet**, an addon mod which implements biomes based off the layers from Casualties: Unknown, including traps and monsters.
